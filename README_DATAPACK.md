# FTB War System Datapack

Полностью готовый **датапак** для Minecraft 1.20.1+ **без модов**.

## Что это:

- ⚔️ **Система войн** между игроками/командами
- 🛡️ **Захват территорий** - метод для управления чанками
- 🎯 **PvP только во время войны** - нельзя бить врагов вне войны
- 📊 **Проверка 39% онлайна** - нельзя начать войну, если враг почти весь оффлайн
- 📍 **Таймеры захвата** - 5 минут на захват территории

## Установка:

1. **Скачай датапак** из репозитория
2. **Положи в папку сервера:**
   ```
   world/datapacks/warmodadd/
   ```
3. **Перезагрузи сервер:** `/reload` или перезапуск
4. **Команды готовы к использованию!** ✅

## Команды:

### `/war <игрок>`
- Объявить войну игроку/команде
- Требует 39%+ врага в онлайне
- Создает запрос на войну

### `/waraccept`
- Принять запрос на войну
- Война начинается сразу после

### `/peace <игрок>`
- Завершить войну
- Создает 5-дневный пакт мира

### `/infowar`
- Показать список врагов
- Показать активные войны

### `/warterritory claim <x> <z>`
- Захватить территорию (5 минут без врагов)

### `/warterritory list`
- Список захватанных территорий

## Как работает захват:

1. Встань на чанк врага
2. Выполни `/warterritory claim <x> <z>`
3. Оставайся на территории 5 минут
4. Если враг не вернется - территория твоя!
5. Враг не может строить на захватанной территории

## Требования:

- ✅ Minecraft 1.20.1+
- ✅ Vanilla сервер (никаких модов!)
- ✅ OperatorOP доступ

## Функции:

### PvP System
- Можно бить врага только если в войне
- Все остальные PvP попытки блокируются

### Territory System
- Захватанные территории защищены
- Враги не могут строить блоки
- Враги не могут ломать блоки

### War Mechanics
- Война длится до мира
- Мир создает 5-дневный пакт
- Во время пакта нельзя объявить войну
